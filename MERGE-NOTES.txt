HOW TO DEPLOY
1. BACK UP the live site files and the database first.
2. Upload this folder's files over the live site (do NOT overwrite includes/config.local.php or uploads/).
3. In phpMyAdmin run performance-indexes.sql once (safe to re-run).
4. The messages table upgrades itself on first open (adds audio_file + 'assistant' role) — needs ALTER permission.
5. Make sure uploads/voice/ exists and is writable by PHP.
6. To enable the AI: add to includes/config.local.php
       define('GEMINI_API_KEY', 'your key');
   and replace every "TODO" answer in includes/osa-faq.php with the official OSA answers
   (entries still marked TODO are ignored). PHP cURL must be enabled.
   NOTE: students' message text is sent to Google's Gemini API — mention this in your privacy notice.
7. Test: voice message send/play (student + OSA), a student message that hits the FAQ, export with filters,
   audit-log paging, students page as STAFF (delete/disable buttons must be hidden and blocked).
